# derive/ — archived Derive project skills

Versioned copies of Derive-specific skills, kept here so they live in the
claude-skills repo alongside everything else. **They are not loaded globally** —
Claude Code only discovers personal skills at `~/.claude/skills/<name>/SKILL.md`
(one level deep), so nesting under `derive/` keeps them inert.

**Canonical, live copies are in the Derive repo** at
`derive-web/.claude/skills/`. Edit there first; refresh the copy here when it
drifts.
