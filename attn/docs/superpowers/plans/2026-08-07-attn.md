# attn Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `attn`, a tailnet page at `http://devbox:4380` that lists only the items needing Eden, and that removes each item automatically the moment it stops being true.

**Architecture:** A CLI writes JSON item files and never contacts the server, so filing survives the service being down. A server thread re-runs each item's `--alive` shell command every 2 minutes and closes the item on exit code 1. Items with no command expire 24 hours after their last file call. Nothing spends model tokens after filing.

**Tech Stack:** Python 3.12 standard library only. No pip, no Node. `systemd --user`, bound to the tailnet IP.

**Spec:** `attn/docs/superpowers/specs/2026-08-07-attn-design.md`

---

## File Structure

All paths are relative to `~/.claude/skills/attn/`.

| File | Responsibility |
|---|---|
| `store.py` | paths, key rules, the global lock, atomic writes, the item schema, open/closed/suppressed state |
| `checker.py` | run one `alive` command, map its exit code, apply the result, sweep every open item |
| `page.py` | render the HTML page, compute the reload digest, humanize ages |
| `attn.py` | the CLI; executable, symlinked to `~/.local/bin/attn` |
| `attn_server.py` | bind, HTTP handler, the checker thread, `main()` |
| `attn.service` | systemd `--user` unit |
| `SKILL.md` | how an agent files an item |
| `test_store.py`, `test_checker.py`, `test_page.py`, `test_cli.py` | one suite per unit |

`store.py` is imported by both the CLI and the server, so the schema is written once. This differs from `worklog.py`, which deliberately duplicates its `STATES` tuple into `server.py`; there the two files live in separate skills, here they live in one directory and sharing is correct.

Tests follow the `worklog/test_cli.py` convention exactly: plain Python, no `unittest`, a `check(cond, msg)` helper, `test_*` functions discovered from `globals()`, and `ATTN_DIR` pointed at a temp directory so no test touches real state.

#!/usr/bin/env python3
"""Shared storage for attn: paths, locking, atomic writes, the item schema.

Both attn.py (the CLI) and attn_server.py (the checker and the page) import
this module, so the item schema is defined exactly once.

Every path helper reads ATTN_DIR on each call rather than caching it at import
time. Tests set the variable and call in-process; caching would pin the first
value and make them share state.
"""
import calendar
import contextlib
import fcntl
import json
import os
import re
import tempfile
import time

KEY_RE = re.compile(r"[a-z0-9][a-z0-9._-]{0,63}\Z")

TTL_SECONDS = 24 * 3600
SNOOZE_SECONDS = 24 * 3600
SUPPRESS_SECONDS = 7 * 24 * 3600
MAX_CHECK_ERRORS = 3


def root():
    return os.path.abspath(os.path.expanduser(
        os.environ.get("ATTN_DIR", "~/attn")))


def base_url():
    return os.environ.get("ATTN_URL", "http://devbox:4380").rstrip("/")


def open_dir():
    return os.path.join(root(), "open")


def suppress_dir():
    return os.path.join(root(), "suppressed")


def closed_path():
    return os.path.join(root(), "closed.jsonl")


def lock_path():
    """A separate file that holds nothing.

    Never lock an item file. write_json swaps the inode with os.replace, so two
    processes that locked open/<key>.json would hold locks on two different
    files and block nothing at all. worklog.py documents hitting exactly this.
    """
    return os.path.join(root(), ".lock")


def open_path(key):
    return os.path.join(open_dir(), f"{key}.json")


def suppress_path(key):
    return os.path.join(suppress_dir(), f"{key}.json")


def ensure_dirs():
    os.makedirs(open_dir(), exist_ok=True)
    os.makedirs(suppress_dir(), exist_ok=True)


def valid_key(key):
    """Lowercase, bounded. Refuses '.', '..' and traversal by construction,
    because the pattern demands [a-z0-9] first and allows no '/'."""
    return bool(key) and bool(KEY_RE.match(key))


def now():
    return time.time()


def iso(epoch_seconds):
    return time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime(epoch_seconds))


def now_iso():
    return iso(now())


def epoch(iso_str):
    """Parse an ISO stamp back to epoch seconds. None on anything unparseable.

    calendar.timegm, not time.mktime: the stamps are UTC and mktime reads local
    time, which would shift every comparison by the box's offset.
    """
    if not iso_str:
        return None
    try:
        return calendar.timegm(time.strptime(iso_str, "%Y-%m-%dT%H:%M:%SZ"))
    except (ValueError, TypeError):
        return None


@contextlib.contextmanager
def lock():
    """Serialise one read-modify-write across the CLI and the server.

    Never held while a check command runs. Checks take up to 10 seconds; this
    is taken only for the microseconds around a write.
    """
    ensure_dirs()
    fd = None
    try:
        fd = os.open(lock_path(), os.O_RDWR | os.O_CREAT, 0o644)
        fcntl.flock(fd, fcntl.LOCK_EX)
    except OSError:
        # A vanished or read-only root. Running unlocked is bad; a traceback is
        # worse, because the CLI's exit codes are documented and callers read
        # them.
        if fd is not None:
            os.close(fd)
            fd = None
    try:
        yield
    finally:
        if fd is not None:
            os.close(fd)  # closing the descriptor releases the flock


def write_json(path, obj):
    """Write atomically, so a reader never sees a half-written file."""
    os.makedirs(os.path.dirname(path), exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=os.path.dirname(path),
                               prefix=".tmp-", suffix=".json")
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as f:
            json.dump(obj, f, indent=2, sort_keys=True)
            f.write("\n")
        os.replace(tmp, path)
    except BaseException:
        with contextlib.suppress(OSError):
            os.unlink(tmp)
        raise


def read_json(path):
    try:
        with open(path, encoding="utf-8") as f:
            return json.load(f)
    except (OSError, ValueError):
        return None
```

def read_item(key):
    return read_json(open_path(key))


def write_item(item):
    write_json(open_path(item["key"]), item)


def list_open():
    """Every open item, oldest filed first. Unreadable files are skipped."""
    ensure_dirs()
    items = []
    try:
        names = os.listdir(open_dir())
    except OSError:
        return []
    for name in names:
        if name.startswith(".") or not name.endswith(".json"):
            continue
        item = read_json(os.path.join(open_dir(), name))
        if item and item.get("key"):
            items.append(item)
    items.sort(key=lambda i: (i.get("filed") or "", i["key"]))
    return items


def default_source():
    return os.environ.get("ATTN_SOURCE") or "unknown"


def upsert(key, title, body=None, project=None, url=None, source=None,
           alive=None, cwd=None):
    """Create or update one item. The caller must hold lock().

    Idempotent on `key`: a loop calls this every cycle and gets one item, with
    `filed` preserved so the page can show a true age.
    """
    stamp = now_iso()
    item = read_item(key)
    if item is None:
        item = {"key": key, "filed": stamp, "checked": None}
    item.update({
        "title": title,
        "body": body,
        "project": project,
        "url": url,
        "source": source or default_source(),
        "alive": alive,
        "cwd": cwd or os.path.expanduser("~"),
        "refiled": stamp,
        "check_errors": 0,
        "last_error": None,
        "snoozed_until": None,
    })
    # A checked item is judged by its command, never by a clock. Setting this
    # to None on every refile also clears a fallback expiry that a broken check
    # left behind.
    item["expires"] = None if alive else iso(now() + TTL_SECONDS)
    item.setdefault("checked", None)
    write_item(item)
    return item
```

def append_closed(record):
    """Append one line to closed.jsonl. A record, never served to the page."""
    ensure_dirs()
    with open(closed_path(), "a", encoding="utf-8") as f:
        f.write(json.dumps(record, sort_keys=True) + "\n")


def close_item(key, reason):
    """Record the item and remove it from open/. The caller must hold lock()."""
    item = read_item(key)
    if item is None:
        return False
    item["closed"] = now_iso()
    item["reason"] = reason
    append_closed(item)
    with contextlib.suppress(OSError):
        os.remove(open_path(key))
    return True


def suppress(key):
    """Block refiles of this key. The caller must hold lock().

    Dismiss without suppression cannot work: the loop that filed the item files
    it again within minutes, and the item is unclearable.
    """
    write_json(suppress_path(key),
               {"key": key, "until": iso(now() + SUPPRESS_SECONDS)})


def suppressed_until(key):
    """The ISO expiry while the key is suppressed, else None."""
    record = read_json(suppress_path(key))
    if not record:
        return None
    until = epoch(record.get("until"))
    if until is None or until <= now():
        return None
    return record["until"]


def purge_expired_suppressions():
    """Delete suppression files that have expired. Returns how many went."""
    ensure_dirs()
    removed = 0
    try:
        names = os.listdir(suppress_dir())
    except OSError:
        return 0
    for name in names:
        if name.startswith(".") or not name.endswith(".json"):
            continue
        path = os.path.join(suppress_dir(), name)
        record = read_json(path)
        until = epoch(record.get("until")) if record else None
        if until is None or until <= now():
            with contextlib.suppress(OSError):
                os.remove(path)
            removed += 1
    return removed
```

#!/usr/bin/env python3
"""Behavioral tests for the attn CLI.

Run: python3 test_cli.py
Exits 0 on success, non-zero (with a FAIL line) otherwise.
Every run points ATTN_DIR at a temp folder, so no test touches the real ~/attn.
"""
import json
import os
import subprocess
import sys
import tempfile

HERE = os.path.dirname(os.path.abspath(__file__))
CLI = os.path.join(HERE, "attn.py")

failures = []


def check(cond, msg):
    if cond:
        print(f"  ok: {msg}")
    else:
        print(f"  FAIL: {msg}")
        failures.append(msg)


def run(root, *args, stdin=None):
    env = dict(os.environ, ATTN_DIR=root, ATTN_URL="http://devbox:4380")
    env.pop("ATTN_SOURCE", None)
    proc = subprocess.run([sys.executable, CLI, *args], capture_output=True,
                          text=True, env=env, input=stdin)

#!/usr/bin/env python3
"""attn — the list of things only Eden can do.

    attn file <key> --title T [--alive CMD] [--cwd DIR] [--body B|-]
                              [--project P] [--url U] [--source S]
    attn done  <key>              close it; the agent finished it after all
    attn list  [--json]           open items, for an agent to read
    attn purge [<key>]            close one item, or every item
    attn url                      print the page URL

Exit codes: 0 ok · 2 unknown key · 4 bad input.

This CLI never contacts the server. It writes plain files, so filing still
works when the service is down and the item appears when it comes back.

File an item only when Eden must do something himself. An item an agent could
finish is not an item.
"""
import argparse
import json
import os
import sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import store  # noqa: E402

EXIT_UNKNOWN_KEY = 2
EXIT_BAD_INPUT = 4


def die(code, msg):
    print(f"attn: {msg}", file=sys.stderr)
    return code


def read_body(value):
    """--body - reads stdin. Returns None when the flag is absent."""
    if value is None:
        return None
    if value == "-":
        return sys.stdin.read().strip() or None
    return value.strip() or None


def cmd_file(args):
    if not store.valid_key(args.key):
        return die(EXIT_BAD_INPUT,
                   f"bad key {args.key!r}: use [a-z0-9][a-z0-9._-]{{0,63}}")
    if not args.title or not args.title.strip():
        return die(EXIT_BAD_INPUT, "--title is required and must not be empty")
    try:
        body = read_body(args.body)
    except UnicodeDecodeError:
        return die(EXIT_BAD_INPUT, "--body must be UTF-8 text")
    with store.lock():
        until = store.suppressed_until(args.key)
        if until:
            store.append_closed({
                "key": args.key, "title": args.title,
                "closed": store.now_iso(), "reason": "suppressed",
            })
            print(f"attn: {args.key} was dismissed and is suppressed until "
                  f"{until}; not filed", file=sys.stderr)
            return 0
        store.upsert(args.key, title=args.title.strip(), body=body,
                     project=args.project, url=args.url, source=args.source,
                     alive=args.alive, cwd=args.cwd)
    return 0


def cmd_done(args):
    if not store.valid_key(args.key):
        return die(EXIT_BAD_INPUT, f"bad key {args.key!r}")
    with store.lock():
        if not store.close_item(args.key, "done"):
            return die(EXIT_UNKNOWN_KEY, f"no open item {args.key!r}")
    return 0


def cmd_list(args):
    items = store.list_open()
    if args.json:
        print(json.dumps(items, indent=2, sort_keys=True))
        return 0
    for item in items:
        print(f"{item['key']}\t{item.get('title', '')}")
    return 0


def cmd_purge(args):
    with store.lock():
        if args.key:
            if not store.valid_key(args.key):
                return die(EXIT_BAD_INPUT, f"bad key {args.key!r}")
            if not store.close_item(args.key, "purged"):
                return die(EXIT_UNKNOWN_KEY, f"no open item {args.key!r}")
            return 0
        for item in store.list_open():
            store.close_item(item["key"], "purged")
    return 0


def cmd_url(args):
    print(store.base_url())
    return 0


def build_parser():
    parser = argparse.ArgumentParser(prog="attn", description=__doc__)
    subs = parser.add_subparsers(dest="command", required=True)

    p = subs.add_parser("file", help="create or update an item")
    p.add_argument("key")
    p.add_argument("--title", required=False)
    p.add_argument("--alive", help="shell command; exit 1 means resolved")
    p.add_argument("--cwd", help="directory the check runs in (default $HOME)")
    p.add_argument("--body", help="plain text detail, or - to read stdin")
    p.add_argument("--project")
    p.add_argument("--url")
    p.add_argument("--source", help="which loop filed this")
    p.set_defaults(func=cmd_file)

    p = subs.add_parser("done", help="close an item")
    p.add_argument("key")
    p.set_defaults(func=cmd_done)

    p = subs.add_parser("list", help="print open items")
    p.add_argument("--json", action="store_true")
    p.set_defaults(func=cmd_list)

    p = subs.add_parser("purge", help="close one item, or every item")
    p.add_argument("key", nargs="?")
    p.set_defaults(func=cmd_purge)

    p = subs.add_parser("url", help="print the page URL")
    p.set_defaults(func=cmd_url)
    return parser


def main(argv):
    args = build_parser().parse_args(argv)
    store.ensure_dirs()
    return args.func(args)


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))

#!/usr/bin/env python3
"""The attn check loop: decide whether each item is still true.

The exit code decides, and the split between 1 and everything else is the
whole design:

    0                       still true    keep the item
    1                       resolved      close the item
    anything else, timeout  broken check  keep it and count the failure

A `grep -q` that finds nothing exits 1, which means the item is genuinely
done. A `gh` that lost its auth exits 127, and so does a missing binary.
Treating those as resolved would silently empty the page, which is a worse
failure than showing something stale.
"""
import concurrent.futures
import contextlib
import os
import signal
import subprocess
import sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import store  # noqa: E402

CHECK_TIMEOUT = 10
SWEEP_SECONDS = 120
POOL_SIZE = 4


def run_check(alive, cwd, timeout=CHECK_TIMEOUT):
    """Run one alive command. Returns (verdict, detail).

    verdict is "alive", "resolved" or "error". The command runs in its own
    session, so a timeout can kill the whole process group rather than leaving
    orphaned children behind.
    """
    try:
        proc = subprocess.Popen(
            ["/bin/sh", "-c", alive],
            cwd=cwd or os.path.expanduser("~"),
            stdout=subprocess.DEVNULL,
            stderr=subprocess.PIPE,
            text=True,
            start_new_session=True,
        )
    except OSError as exc:
        return "error", f"could not start: {exc}"

    try:
        _, err = proc.communicate(timeout=timeout)
    except subprocess.TimeoutExpired:
        with contextlib.suppress(OSError, ProcessLookupError):
            os.killpg(os.getpgid(proc.pid), signal.SIGKILL)
        with contextlib.suppress(Exception):
            proc.communicate(timeout=5)
        return "error", f"timeout after {timeout}s"

    code = proc.returncode
    if code == 0:
        return "alive", ""
    if code == 1:
        return "resolved", ""
    lines = (err or "").strip().splitlines()
    tail = lines[-1][:200] if lines else "no stderr"
    return "error", f"exit {code}: {tail}"
```

def apply_result(key, verdict, detail, refiled_at):
    """Write one check result back. Returns what happened, for the log.

    The command ran outside the lock, because it takes up to 10 seconds. A loop
    can refile the item during that window, so the item is re-read here and
    `refiled` compared. A changed stamp means the verdict describes an older
    version of the item, and the refile wins.
    """
    with store.lock():
        item = store.read_item(key)
        if item is None:
            return "gone"
        if item.get("refiled") != refiled_at:
            return "refiled"

        if verdict == "resolved":
            store.close_item(key, "resolved")
            return "resolved"

        item["checked"] = store.now_iso()
        if verdict == "alive":
            item["check_errors"] = 0
            item["last_error"] = None
            if item.get("alive"):
                item["expires"] = None
            store.write_item(item)
            return "alive"

        item["check_errors"] = int(item.get("check_errors") or 0) + 1
        item["last_error"] = detail
        if (item["check_errors"] >= store.MAX_CHECK_ERRORS
                and not item.get("expires")):
            item["expires"] = store.iso(store.now() + store.TTL_SECONDS)
        store.write_item(item)
        return "error"


def _close_if_expired(item):
    """True when the item was expired and has now been closed."""
    expires = store.epoch(item.get("expires"))
    if expires is None or expires > store.now():
        return False
    with store.lock():
        return store.close_item(item["key"], "expired")


def _backfill_expiry(key):
    """Give an item with neither a check nor an expiry a 24h clock.

    Only a hand-edited file reaches this. Without it the item would live
    forever unchecked, which is the exact failure this whole tool exists to
    prevent.
    """
    with store.lock():
        item = store.read_item(key)
        if item is None or item.get("alive") or item.get("expires"):
            return
        base = store.epoch(item.get("filed")) or store.now()
        item["expires"] = store.iso(base + store.TTL_SECONDS)
        store.write_item(item)


def sweep():
    """One pass over every open item. Returns a count dict for the log."""
    store.ensure_dirs()
    counts = {"checked": 0, "resolved": 0, "expired": 0,
              "errors": 0, "refiled": 0}
    store.purge_expired_suppressions()

    pending = []
    for item in store.list_open():
        if _close_if_expired(item):
            counts["expired"] += 1
            continue
        if not item.get("alive"):
            if not item.get("expires"):
                _backfill_expiry(item["key"])
            continue
        pending.append(item)

    if not pending:
        return counts

    with concurrent.futures.ThreadPoolExecutor(max_workers=POOL_SIZE) as pool:
        futures = {
            pool.submit(run_check, item["alive"], item.get("cwd")): item
            for item in pending
        }
        for future in concurrent.futures.as_completed(futures):
            item = futures[future]
            verdict, detail = future.result()
            outcome = apply_result(item["key"], verdict, detail,
                                   item.get("refiled"))
            counts["checked"] += 1
            if outcome in counts:
                counts[outcome] += 1
            elif outcome == "error":
                counts["errors"] += 1
    return counts


def sweep_forever(stop_event):
    """Sweep, wait, repeat. The wait starts after the sweep finishes, so a slow
    sweep never stacks up behind itself."""
    while not stop_event.is_set():
        try:
            counts = sweep()
            if any(counts[k] for k in ("resolved", "expired", "errors")):
                print(f"attn sweep: {counts}", flush=True)
        except Exception as exc:            # never let the thread die
            print(f"attn sweep failed: {exc!r}", file=sys.stderr, flush=True)
        stop_event.wait(SWEEP_SECONDS)
```

Note on `counts`: `apply_result` returns `"resolved"`, `"alive"`, `"error"`, `"refiled"` or `"gone"`. Only `resolved` and `refiled` are keys in `counts`, so the `elif` handles `error` and `alive`/`gone` fall through uncounted, which is correct.

def digest(items):
    """A short hash of the open set.

    `checked` is deliberately outside the hash. Including it would change the
    digest on every sweep and reload the page under Eden every 2 minutes.
    """
    parts = [
        "|".join([
            item.get("key") or "",
            item.get("title") or "",
            item.get("snoozed_until") or "",
            str(item.get("check_errors") or 0),
        ])
        for item in sorted(items, key=lambda i: i.get("key") or "")
    ]
    return hashlib.sha256("\n".join(parts).encode("utf-8")).hexdigest()[:16]

#!/usr/bin/env python3
"""The attn server: run the checks, serve the page, accept two actions.

    attn_server.py [port]        default 4380, or $ATTN_PORT

Bound to the tailnet IP, never 0.0.0.0. This box has a public interface, and
the page names internal work.
"""
import json
import os
import signal
import subprocess
import sys
import threading
import urllib.parse
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import checker  # noqa: E402
import page  # noqa: E402
import store  # noqa: E402

DEFAULT_PORT = 4380


def bind_host():
    """Resolve the interface to bind.

    Never 0.0.0.0: this box has a public interface. Prefer the tailnet IP,
    which reaches Eden's laptop and nowhere else. Fall back to loopback only
    when tailscale cannot answer — attn.service refuses to start in that case,
    so the fallback is for a hand-run server and for tests.
    """
    override = os.environ.get("ATTN_BIND")
    if override:
        return override
    try:
        proc = subprocess.run(["tailscale", "ip", "-4"], capture_output=True,
                              text=True, timeout=3)
        if proc.returncode == 0:
            for line in proc.stdout.splitlines():
                address = line.strip()
                if address:
                    return address
    except (OSError, subprocess.SubprocessError):
        pass
    return "127.0.0.1"


def do_action(key, action):
    """Apply a page action. Returns True when it changed something."""
    if not store.valid_key(key) or action not in ("dismiss", "snooze"):
        return False
    with store.lock():
        item = store.read_item(key)
        if item is None:
            return False
        if action == "dismiss":
            store.close_item(key, "dismissed")
            store.suppress(key)
            return True
        item["snoozed_until"] = store.iso(store.now() + store.SNOOZE_SECONDS)
        store.write_item(item)
        return True


class Handler(BaseHTTPRequestHandler):
    server_version = "attn/1.0"

    def _send(self, code, body, content_type="text/html; charset=utf-8"):
        payload = body.encode("utf-8")
        self.send_response(code)
        self.send_header("Content-Type", content_type)
        self.send_header("Content-Length", str(len(payload)))
        self.send_header("Cache-Control", "no-store")
        self.end_headers()
        self.wfile.write(payload)

    def do_GET(self):
        path = urllib.parse.urlparse(self.path).path
        if path == "/":
            self._send(200, page.render(store.list_open()))
            return
        if path == "/digest":
            visible = page.visible(store.list_open())
            self._send(200, page.digest(visible), "text/plain; charset=utf-8")
            return
        if path == "/state.json":
            self._send(200, json.dumps(store.list_open(), indent=2,
                                       sort_keys=True),
                       "application/json; charset=utf-8")
            return
        self.send_error(404, "no such path")

    def do_POST(self):
        path = urllib.parse.urlparse(self.path).path
        if path != "/action":
            self.send_error(404, "no such path")
            return
        try:
            length = int(self.headers.get("Content-Length") or 0)
        except ValueError:
            length = 0
        if length <= 0 or length > 4096:
            self.send_error(400, "bad body")
            return
        fields = urllib.parse.parse_qs(self.rfile.read(length).decode("utf-8"))
        key = (fields.get("key") or [""])[0]
        action = (fields.get("action") or [""])[0]
        if not do_action(key, action):
            self.send_error(400, "bad key or action")
            return
        self.send_response(303)
        self.send_header("Location", "/")
        self.send_header("Content-Length", "0")
        self.end_headers()

    def log_message(self, fmt, *args):
        # One line per action, nothing per page poll: the reload script hits
        # /digest every 15 seconds and would bury the journal.
        if self.command == "POST":
            sys.stderr.write(f"attn {self.command} {self.path}\n")


def build_server(host, port):
    return ThreadingHTTPServer((host, port), Handler)


def main(argv):
    port = int(argv[0]) if argv else int(os.environ.get("ATTN_PORT",
                                                        DEFAULT_PORT))
    store.ensure_dirs()
    host = bind_host()
    httpd = build_server(host, port)

    stop = threading.Event()
    thread = threading.Thread(target=checker.sweep_forever, args=(stop,),
                              daemon=True)
    thread.start()

    def shutdown(signum, frame):
        stop.set()
        threading.Thread(target=httpd.shutdown, daemon=True).start()

    signal.signal(signal.SIGTERM, shutdown)
    signal.signal(signal.SIGINT, shutdown)

    print(f"attn serving http://{host}:{port} "
          f"(sweep every {checker.SWEEP_SECONDS}s)", flush=True)
    try:
        httpd.serve_forever()
    finally:
        stop.set()
        httpd.server_close()
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))

# attn.service — the list of things only Eden can do (tailnet only).
#
#   open:    http://devbox:4380
#   watch:   journalctl --user -u attn.service -f
#   stop:    systemctl --user stop attn
#   remove:  systemctl --user disable --now attn.service \
#              && rm ~/.config/systemd/user/attn.service
#
# WARNING: this service runs agent-authored shell every 2 minutes, as Eden.
# Each open item's --alive command is executed by the check loop. Agents
# already have Bash, so this grants no new capability; it grants persistence,
# because a command filed once keeps running after the session that wrote it
# ends. `attn purge` drops every open item and stops every check at once.
#
# Environment=PATH is not decoration, and carries two separate jobs:
#   * attn_server.bind_host() runs `tailscale ip -4`. Under a minimal systemd
#     PATH that lookup raises OSError, the bind falls back to 127.0.0.1, and
#     the service comes up healthy but invisible from Eden's laptop.
#   * Every item check inherits this environment. A check that works in Eden's
#     shell and fails here is the most likely early bug, which is why the page
#     shows last_error rather than hiding it.
#
# Enable with:  systemctl --user daemon-reload && systemctl --user enable --now attn
[Unit]
Description=attn — items needing Eden (tailnet only)
# Both lines are advisory only: this is a --user unit, and neither target
# exists in the user manager. ExecStartPre below is what holds the guarantee.
After=network-online.target tailscaled.service
StartLimitIntervalSec=0

[Service]
Type=simple
Environment=PATH=%h/.local/bin:%h/.local/share/fnm/node-versions/v24.15.0/installation/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
WorkingDirectory=%h/.claude/skills/attn
# Refuse to start until `tailscale ip -4` answers — the exact call bind_host()
# makes. Failing here is correct: Restart=always retries until the tailnet is
# up, which beats serving on 127.0.0.1 while reporting success.
ExecStartPre=/bin/sh -c 'for i in $(seq 60); do tailscale ip -4 >/dev/null 2>&1 && exit 0; sleep 1; done; echo "tailscale ip -4 never answered; refusing to bind 127.0.0.1" >&2; exit 1'
ExecStart=/usr/bin/python3 %h/.claude/skills/attn/attn_server.py 4380
Restart=always
RestartSec=5
SyslogIdentifier=attn
Nice=10

[Install]
WantedBy=default.target
```

# attn — the list of things only Eden can do

An agent that hits a wall writes the fact into a report nobody opens, and the
fact dies with the session. `attn` is where that fact goes instead.

## The one rule

**File an item only when Eden must act himself.** Something you could finish,
retry, or work around is not an item. The list is worth reading only while
every line on it is genuinely his.

## File it with a check

```bash
attn file derive-pr-412 \
  --title "Approve the schema change on PR #412" \
  --alive 'gh pr view 412 --repo eden/derive --json state -q .state | grep -q OPEN' \
  --cwd ~/code/Derive \
  --project Derive \
  --url https://github.com/eden/derive/pull/412 \
  --source mewt-audit
```

The `--alive` command is re-run every 2 minutes:

| Exit | Meaning |
|---|---|
| 0 | still true — the item stays |
| 1 | resolved — the item is removed |
| anything else | the check is broken — the item stays and is marked |

So the item disappears by itself the moment Eden merges that PR. Nobody has to
remember to close it.

**Write a check that reads the source of truth**, not one that reads your own
output. Good: `gh pr view`, `test -f`, `grep -q` over a live file, a `psql -c`
that counts rows. Bad: anything testing a file you wrote yourself.

`--cwd` matters for any check that needs a repo. It defaults to `$HOME`.

## Filing without a check

Some items no command can test — "decide whether we ship the new pricing".
Omit `--alive` and the item expires 24 hours later.

```bash
attn file pricing-call --title "Decide whether the new pricing ships this week"
```

If a loop still cares tomorrow, it files again and the clock resets. A one-off
session's item is simply gone by the next day, which is correct: nobody is
left asserting it.

## Refile freely

`attn file` is idempotent on the key. A loop calls it on every cycle and gets
one item, with its original age preserved. Never invent a per-run key.

## The rest of the commands

```
attn done  <key>       you finished it after all; close it
attn list  [--json]    what is open
attn purge [<key>]     close one item, or every item
attn url               print http://devbox:4380
```

Exit codes: `0` ok · `2` unknown key · `4` bad input.

Filing a key Eden dismissed prints a line to stderr and exits 0 without
creating anything. A dismiss suppresses the key for 7 days, so your loop
cannot force it back.

## Which server

| What you have | Use | Port |
|---|---|---|
| Something only Eden can do | **attn** | 4380 |
| Progress on one long task | `worklog` | 4370 |
| HTML you are designing | `html-design` | 4321 |
| A finished artifact | `preview` | 4340 |

## Rules

- **Claim a key from the thing, not the session.** `derive-pr-412`, not
  `task1`. Lowercase, digits, `-`, `.`, `_`, 64 characters at most.
- **Set `--project`** so the page groups usefully.
- **Set `--source`** to the loop's name, or export `ATTN_SOURCE` once.
- **Never file something you could do.** That is the whole rule.

## When it breaks

```bash
systemctl --user status attn
journalctl --user -u attn.service -n 50
systemctl --user restart attn
```

A check that works in your shell but fails under systemd is the usual cause,
because item checks inherit the unit's `PATH`. The page shows `last_error` for
exactly this.

The CLI never contacts the server, so filing still lands on disk while the
service is down.
